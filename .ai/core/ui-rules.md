# UI Rules

Production UI follows the approved reference workflow.

Reference priority:

1. Approved screenshots under `docs/references/`.
2. Approved Tio Ledger mockups.
3. Decompiled Money Manager technical reference for permitted analysis only.
4. Official Money Manager website.
5. Official Play Store screenshots.

Rules:

- Do not invent or redesign major workflows without approval.
- Preserve familiar behavior unless an intentional deviation is documented.
- Use decompiled references only for workflow, navigation, hierarchy,
  terminology, grouping, and interaction analysis.
- Never copy proprietary code, XML, resources, assets, or implementation
  details.
- Require a reference note, functional specification, navigation definition,
  acceptance checklist, accessibility review, and applicable visual review.
